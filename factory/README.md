# 📱🏭 CTO AI — المصنع (Factory APK)

تطبيق أندرويد **Java أصيل 100%** — نسخة جيب من منصة BuildAI:
تسجل دخول بـ GitHub Token، توصف تطبيقك، والمصنع **داخل جوالك** يولّد
مشروع أندرويد كامل (Java + XML + Gradle)، يرفعه ع حسابك، ويشغّل
GitHub Actions، وبعدين **ينزّل الـ APK الجاهز إلى التنزيلات** 🎉

- بدون WebView — واجهة native كاملة
- بدون سيرفر — التوليد والرفع يشتغلون من الجوال مباشرة
- بدون مكتبات خارجية — java.net + org.json فقط
- البناء الثقيل (Gradle) ع GitHub Actions المجاني، والنتيجة ترجع لجوالك

هذا المجلد يُبنى تلقائياً بالـ workflow الرئيسي للريبو.
